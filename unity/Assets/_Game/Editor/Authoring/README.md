# Authoring tools

Editor-only tools for making levels, content and balance changes. Menu root: **Tools > Hold the Hill > Authoring**. Code is in this folder, namespace `HoldTheHill.Sandbox.NillyCtrl.Editor`. None of it runs in a build.

## Level Grid Importer
`Tools > Hold the Hill > Authoring > Level Grid Importer`

1. Pick a map from `Levels/Source~/maps/` (variants included). The window re-reads the file when it changes.
2. It checks the map with the rules of `level_grid.py` (one S, one hill, one unbranched road, no road touching itself) and shows a colour preview, the buildable cells (green dots) and an ASCII view.
3. If the floor picture and json for the map are missing, **Generate floor picture + json** runs `python build_level.py --install` (needs python with Pillow).
4. **Build level scene** calls `GrayboxLevelBuilder.Build(<AssetName>)`. It rebuilds the graybox scene first, so close Play mode and take the session lock.

## Content Wizard
`Tools > Hold the Hill > Authoring > Content Wizard`

Tabs for **Tower**, **Enemy / Boss**, **Pickup**, **Power-up**. Each makes the data asset and a prefab variant of the existing base prefab, the way the graybox builders do. Anything that already exists is left untouched (the Create button is disabled and says why).

- Tower: variant of `TowerBase` or of another tower, `TowerData`, optional catalog entry. Note "Rebuild Graybox Tower Prefabs" resets the catalog list to the built-in towers.
- Enemy / Boss: variant of `GrayboxEnemyBase` or `GrayboxBossBase` (`Graybox<Id>.prefab`), plus a `GrayboxBossData` for bosses. Special behaviour is added by hand.
- Pickup: variant of `PickupBase` paying a `GrayboxResourceData`.
- Power-up: `GrayboxPowerUpData`, effect prefab (pick any `GrayboxPowerUpEffect` subclass) and pickup variant. Can add it to the open scene's `GrayboxPowerUpSpawner`; save the scene afterwards.

## Wave & Balance Editor
`Tools > Hold the Hill > Authoring > Wave and Balance Editor`

Pick a `MapWaveDataSO` (defaults to `GrayboxWaves`). The table shows each wave's enemy count, HP pool (health plus shield), seconds to spawn, bounty and a rough DPS needed (HP pool / (spawn seconds + "time under fire")). Select a wave to edit its enemies and delays, add enemies by type, duplicate, reorder or delete waves. Edits are undoable; **Save** writes the asset. The foldout at the bottom previews the endless waves from `GrayboxProceduralWaveGenerator` (read only).

## Balance CSV
`Tools > Hold the Hill > Authoring > Balance CSV`

- **Export Towers / Enemies and Bosses / Power-ups / All** writes `Balance~/towers.csv`, `enemies.csv`, `powerups.csv` next to this sandbox (`_Sandbox/nilly-ctrl/Balance~/`, ignored by Unity). Open them in a spreadsheet.
- **Import (preview changes first)** reads a CSV and lists every change as old -> new without touching anything. **Apply** writes them through SerializedObject as one undo step.
- Rows are matched on the `asset` column (project path). Blank cells and read-only columns (`name`, `boss`, `projectile`, power-up `id`) are ignored. Negative numbers and unknown enum names are rejected in the preview.
- `projectileDamage` edits the projectile prefab, which can be shared by several towers; conflicting rows are rejected.
- Enemy and boss prefabs are regenerated by `GrayboxBuilder` on every build, so imported enemy numbers last only until the next rebuild unless the builder is changed to match.
