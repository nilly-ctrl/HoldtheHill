HOLD THE HILL FONTS

Sixteen hand-drawn pixel alphabets with inline game icons, 48 baked colour styles (eleven of them animated), and a full set repainted for each of 13 art themes. Type below, pick a theme, an alphabet and a colour treatment, and combine them freely. Built 2026-10-06; none of it has been looked at inside Unity yet.

To keep this treatment, add that line to PAINTS in Fonts/Source~/build_faces.py. The name becomes part of the baked file's name.

Style's own and Theme's own show each style as it is baked for the game. Picking an alphabet, a colour treatment, bold or italic repaints every style that way, which previews a pairing that is not baked yet. Most baked styles hold capitals, digits and + - . , % ! ? / : x ( ) only, so lowercase shows as capitals; the Serif and Round styles have real lowercase. Banners, the combo counter and neutral text change most between themes. Damage colours shift only where a theme has its own fire, acid or arcane colours.

KEY AND GAMEPAD PROMPTS

    
In every alphabet's TTF, with names in PixelGlyphs.cs. Write PixelGlyphs.KeySpace in a string, or PixelGlyphs.Key('e') for a letter or digit.

    

  


  

    
BEFORE YOU RELY ON IT

    
    
      
  • Not yet seen in Unity. The TTF files were compared pixel for pixel with the drawings outside Unity, and the C# compiles.
    • 
      
  • Body line height is 10 pixels, up from 9, and mixed-case strings now show as written instead of as capitals.
    • 
      
  • The UI kit still shows the old font until its TextMeshPro font asset is rebuilt.
    • 
      
  • Kerning in Unity is unconfirmed. Legacy Text and IMGUI ignore it; TextMeshPro is untested.
    • 
      
  • Nothing in the game uses the Display or Tiny alphabets, the extra alphabets, the banner and combo styles, or the themed sets yet.
