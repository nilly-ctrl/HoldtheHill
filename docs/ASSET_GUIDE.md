# Hold the Hill: art and UI asset guide

What exists, where it lives, how to use it in Unity and how to change it. Everything below is under `unity/Assets/_Sandbox/nilly-ctrl/` and is pixel art on a 32-pixels-per-unit grid.

## Three rules for all of it

1. **Scale by whole numbers** (2x, 3x, 4x). Anything else makes uneven pixels.
2. **Import with Point filter, no compression.** The importer scripts in `Editor/` do this for the folders they cover. If something looks blurry, right-click it and Reimport.
3. **Don't edit the PNGs by hand.** Each set is generated by a Python script in a `Source~` folder next to it (Unity ignores folders ending in `~`). Change the script, run it, and the PNGs keep their names and `.meta` files.

## Icon names

Files are `<Group><Name>Icon.png`. The group tells you the badge:

| Prefix | Badge | Examples |
|---|---|---|
| `Tower` | Amber square | `TowerLinearIcon`, `TowerFrostAuraIcon` |
| `Enemy` | Red square | `EnemyRunnerIcon`, `EnemyBruteIcon` (graybox enemies); `EnemyScarabIcon` (design-doc roster) |
| `Ach` | Blue crest | `AchFirstBloodIcon`, `AchFortressIcon` |
| `Ability` | Purple square | `AbilityRallyIcon` |
| `Res` | Green square | `ResFoodIcon`, `ResQueenHealthIcon`, `ResWaveIcon` |
| `Dmg`, `Status`, `Combo`, `Target` | Round | `DmgFireIcon`, `StatusBurnIcon`, `TargetFirstIcon` |
| `Skill` | Hexagon, coloured by branch | `SkillControlDeepFreezeIcon` |
| `Ui` | No badge | `UiPlayIcon`, `UiLockIcon` |

Skill icons are named after the `SkillNodeId`: `Control_DeepFreeze` becomes `SkillControlDeepFreezeIcon`.

## Using them

**An icon in the graybox HUD (IMGUI):**

```csharp
Texture2D icon = GrayboxIcons.Get("TowerLinearIcon");   // null if missing
GUI.DrawTexture(new Rect(x, y, 32, 32), icon);
```

`GrayboxIcons` is added to the scene by `GrayboxBuilder` and holds every icon, so this also works in a build.

**An icon in a Canvas:** drag the PNG from `Icons/PNG/` onto an Image. It is already a Sprite.

**A floating number:**

```csharp
DamageNumberSpawner.Show(42, DamageNumberKind.Fire, enemy.position);
DamageNumberSpawner.ShowText("MISS", DamageNumberKind.Physical, enemy.position);
```

Hits, heals and bounties on anything with `EnemyHealth` show up without any code. Set `info.IsCritical = true` on a `DamageInfo` for the crit style.

**Text in the pixel font:** use `Fonts/TTF/HoldTheHillPixel-Regular.ttf` or `-Bold.ttf` at size 10, 20 or 30. It has real lowercase since 2026-10-06, so a mixed-case string now shows as written. For headings use `HoldTheHillDisplay-Regular.ttf` at size 20 or 40, and for very small labels `HoldTheHillTiny-Regular.ttf` at size 10 (both capitals only). Key and gamepad prompts and symbols are named in `DamageNumbers/PixelGlyphs.cs`. See `Fonts/README.md`.

**A stretchy HUD piece** (bar frame, tooltip, cost tag, slot): set the Image to **Sliced**. Slice borders are in `Ui/Hud/Source~/borders.json`.

## Regenerating

```
cd unity/Assets/_Sandbox/nilly-ctrl/Icons/Source~
python build_pixel_icons.py
```

Needs Python 3 with Pillow (`pip install pillow`). The font script also needs `fonttools` for the TTFs. Every script writes a preview sheet into its own `Source~` folder, so check that before opening Unity.

After changing the font atlases, run **Hold the Hill > Sandbox > Build Pixel Fonts** in Unity. After changing icons, run **Tools > Hold the Hill > Build Graybox Combat Test** so the scene picks up any new ones.

## Known gaps

- The cursors and tile markers in `Ui/Markers/` are not used by the graybox yet.
- The graybox scene has to be rebuilt once (**Tools > Hold the Hill > Build Graybox Combat Test**) before the HUD pieces, achievement icons and the three newer enemy status icons appear.
- The title backdrop is art only; there is no title screen yet (see `PLAN_MENUS_AND_FLOW.md`, theme 7).
- The tower icon names (Spitter, Bombardier and so on) are suggestions, not agreed names.
